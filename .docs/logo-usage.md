# Logo usage

## The mark

A lemon cross-section whose pith reads as a fibre patch panel: eight segments, eight jacketed strands terminated in the rind. Playful object, precise engineering — both halves must survive any reproduction.

## Versions

- **Primary** — full colour on paper or ink. Default everywhere there is room.
- **One colour** — ink on light, or knocked out of a solid. For screenprint, embroidery, etch, single-plate print.
- **Small-size crop** — four segments and four strands. Use below 24px on screen or 9mm in print.

## Lockups

- **Horizontal** — mark left, wordmark right, gap equals one connector width.
- **Stacked** — mark above wordmark, centred, for narrow or square placements.
- **Wordmark alone** — only where the mark already appears in the same view.

## Clear space and minimum size

Clear space on all four sides equals **x**, the width of one strand connector (8.5% of mark diameter). Minimum sizes: 24px screen / 9mm print for the full mark, 16px for the small-size crop.

## Colour pairings

| Background | Mark | Wordmark |
| --- | --- | --- |
| `--lf-color-paper` | primary | ink + `--lf-color-fiber-deep` on "fiber" |
| `--lf-color-ink` | primary on ink | paper + `--lf-color-lemon` on "fiber" |
| `--lf-color-fiber-deep` | knockout | paper, single colour |
| Photography | knockout in paper | paper, single colour |

## Don't

- Add a tagline, descriptor, or strapline to the lockup.
- Recolour segments or strands outside the token palette.
- Rotate, skew, stretch, or add gradients, bevels, or drop shadows to the mark (the sticker lift shadow in mockups is on the sticker, not the mark).
- Place the full mark below 24px — switch to the crop.
- Set the wordmark in any face other than Bricolage Grotesque 800.
- Outline the mark or set it in an unapproved colour to "match" a partner brand.
